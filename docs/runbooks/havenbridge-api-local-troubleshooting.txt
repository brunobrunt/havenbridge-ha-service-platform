## PURPOSE

This runbook documents the commands used to start, test, and troubleshoot the
HavenBridge FastAPI backend during local development.

The FastAPI application runs locally on the host named syrus.

PostgreSQL runs inside the HavenBridge Kubernetes cluster.

Connection flow:

HavenBridge FastAPI on syrus
|
v
127.0.0.1:15432
|
v
SSH tunnel through eph-cp01
|
v
Kubernetes PostgreSQL Service
|
v
havenbridge-postgres-0

3. CHECK WHETHER LOCAL PORT 15432 IS ALREADY IN USE
===================================================

Run:

sudo ss -ltnp | grep ':15432'

Alternative:

sudo lsof 
-iTCP:15432 
-sTCP:LISTEN

Check for an existing SSH tunnel:

ps -ef | grep '[s]sh.*15432'

If an SSH process is already forwarding:

15432:10.102.178.240:5432

do not start another tunnel.

============================================================
4. START THE POSTGRESQL SSH TUNNEL
==================================

Retrieve the current PostgreSQL Service ClusterIP:

POSTGRES_CLUSTER_IP="$(
ssh 
-i /home/alabi/.ssh/eph_k8s 
mino@172.16.10.31 
"kubectl get service havenbridge-postgres 
-n havenbridge 
-o jsonpath='{.spec.clusterIP}'"
)"

Start the tunnel in the foreground:

ssh 
-N 
-o ExitOnForwardFailure=yes 
-o ServerAliveInterval=60 
-o ServerAliveCountMax=3 
-i /home/alabi/.ssh/eph_k8s 
-L "15432:${POSTGRES_CLUSTER_IP}:5432" 
mino@172.16.10.31

The terminal remains occupied while the tunnel is active.

This is normal.

To stop the foreground tunnel, press:

Ctrl+C

## START THE TUNNEL IN THE BACKGROUND

Run:

ssh 
-fN 
-o ExitOnForwardFailure=yes 
-o ServerAliveInterval=60 
-o ServerAliveCountMax=3 
-i /home/alabi/.ssh/eph_k8s 
-L "15432:${POSTGRES_CLUSTER_IP}:5432" 
mino@172.16.10.31

Confirm:

ps -ef | grep '[s]sh.*15432'

Stop the background tunnel:

pkill -f 'ssh.*15432:.*:5432'

## COMMON TUNNEL ERROR

Error:

bind [127.0.0.1]:15432: Address already in use

Meaning:

Another program or an existing SSH tunnel is already listening on port 15432.

Investigate with:

sudo ss -ltnp | grep ':15432'

ps -ef | grep '[s]sh.*15432'

## COMMON TABLE ERROR

Error:

relation "service_inquiries" does not exist

Meaning:

The FastAPI SQLAlchemy model exists, but the corresponding PostgreSQL table
has not yet been created.

Confirm that:

1. app/models.py defines ServiceInquiry.
2. app/main.py imports app.models.
3. app/main.py runs Base.metadata.create_all().
4. DB_AUTO_CREATE_TABLES=true is configured.
5. The SSH tunnel is active when FastAPI starts.

23. CHECK WHETHER .env OR .venv IS STAGED
=========================================

Safe check that does not close the terminal:

if git diff --cached --name-only |
grep -qE '(^|/).env$|(^|/).venv/'; then
echo "ERROR: Secret or virtual-environment content is staged."
else
echo "PASS: No .env or .venv files are staged."
fi

## DISPLAY THE MATCHING STAGED PATHS

Run:

git diff --cached --name-only |
grep -E '(^|/).env$|(^|/).venv/'

## IMPORTANT

Do not use "exit 1" in an interactive terminal safety check unless intentionally
exiting the current shell.

This command can close an interactive terminal:

exit 1
