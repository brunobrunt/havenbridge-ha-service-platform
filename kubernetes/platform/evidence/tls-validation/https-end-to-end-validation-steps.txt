HavenBridge TLS Phase — End-to-End HTTPS Validation Steps
=========================================================

Purpose
-------
Validate the complete HavenBridge HTTPS path while temporarily bypassing local
CA trust verification.

Project destination
-------------------
/home/alabi/projects/havenbridge-ha-service-platform/kubernetes/platform/evidence/tls-validation/

Command
-------
curl -vk https://havenbridge.lab/health/ready

Validation criteria
-------------------
Confirm:
- DNS resolves havenbridge.lab to 172.16.10.40
- TCP/443 connection succeeds
- TLS 1.3 handshake succeeds
- Traefik presents the havenbridge.lab certificate
- Certificate issuer is HavenBridge Root CA
- HTTP/2 request reaches the application
- /health/ready returns HTTP 200
- Response body is {"status":"ready"}

Note
----
-k is used only for this diagnostic because Syrus does not yet trust the
HavenBridge private Root CA.
