# HavenBridge PostgreSQL Persistence Validation

Validation Date: July 27, 2026
Namespace: havenbridge
StatefulSet: havenbridge-postgres
Pod: havenbridge-postgres-0
Container: postgresql
Database: havenbridge
Database User: havenbridge_admin

## Purpose

This validation confirms that the HavenBridge PostgreSQL StatefulSet uses persistent NFS-backed storage and that database records remain available after the PostgreSQL pod is deleted and recreated.

## Storage Flow

PostgreSQL StatefulSet
|
v
volumeClaimTemplates
|
v
PVC created automatically
|
v
havenbridge-nfs StorageClass
|
v
NFS-backed PersistentVolume

# Validation Result

The PostgreSQL persistence test is successful when all of the following conditions are met:

1. The PostgreSQL PVC remains Bound.
2. The PersistentVolume name remains unchanged.
3. The recreated pod has a different pod UID.
4. The recreated pod mounts the original PVC.
5. PostgreSQL starts successfully.
6. The platform_validation table remains available.
7. The original validation record remains unchanged.

# Conclusion

The HavenBridge PostgreSQL StatefulSet successfully persists database data outside the lifecycle of an individual pod.

Deleting havenbridge-postgres-0 caused the StatefulSet controller to create a new pod. The new pod reattached the existing PVC, mounted the original NFS-backed PersistentVolume, and recovered the previously stored PostgreSQL database and validation record.

This confirms that the HavenBridge PostgreSQL workload uses durable NFS-backed persistent storage through the havenbridge-nfs StorageClass.
