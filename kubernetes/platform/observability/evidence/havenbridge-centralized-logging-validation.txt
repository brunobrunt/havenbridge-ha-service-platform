ALLOY RBAC HARDENING
==================================================================

The default Alloy Helm chart rendered broader read permissions than required
for the HavenBridge log-only use case.

Default permissions included access to resources such as:

Secrets
ConfigMaps
Events
PrometheusRules
AlertmanagerConfigs
ServiceMonitors
PodMonitors


The HavenBridge configuration was reduced to read-only access to:

pods
pods/log
namespaces


Allowed verbs:

get
list
watch


Alloy does NOT receive:

create
update
patch
delete


Final rendered ClusterRole:

pods:
  get
  list
  watch

namespaces:
  get
  list
  watch

pods/log:
  get
  list
  watch


Result:

PASS


==================================================================
ALLOY RBAC HELM RENDERING TROUBLESHOOTING
==================================================================

The first least-privilege configuration used:

clusterRules: []


With Alloy Helm chart 1.12.1 this resulted in:

YAML parse error on alloy/templates/rbac.yaml

yaml: line 23: did not find expected '-' indicator


The chart appends rules and clusterRules into the same ClusterRole.

The configuration was changed so that:

rules:
  pods
  namespaces

clusterRules:
  pods/log

KUBERNETES API VIP CONNECTIVITY INCIDENT
==================================================================

During the first real Alloy Helm installation attempt, connectivity to the
Kubernetes API VIP was temporarily interrupted.


Kubernetes API endpoint:

k8s-api.lab:6443


VIP:

172.16.10.30:6443


Observed messages included:

http2: client connection lost

and:

dial tcp 172.16.10.30:6443: connect: no route to host


The failure occurred while Helm was watching Kubernetes resources.


This was identified as a Kubernetes API VIP/network connectivity issue rather
than an Alloy YAML, RBAC, or application configuration problem.


The installation subsequently completed successfully.


Operational lesson:

Alloy configuration failure
        !=
Kubernetes API/control-plane connectivity failure


Result:

RESOLVED
