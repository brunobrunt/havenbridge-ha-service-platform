Validation and Troubleshooting Commands Used
--------------------------------------------

The following commands were used during Observability Phase 6 to
validate Prometheus alert expressions, alert state transitions,
Alertmanager delivery, application recovery, and Discord
notification delivery.


1. Check HavenBridge Application Request Rate
---------------------------------------------

curl -sG \
  http://127.0.0.1:9090/api/v1/query \
  --data-urlencode 'query=sum(rate(havenbridge_http_requests_total{namespace="havenbridge",route!~"/health/(live|ready)"}[5m]))' \
  | jq '.data.result'


2. Generate Normal HavenBridge Traffic
--------------------------------------

for i in {1..20}; do
  curl -s https://havenbridge.lab/ > /dev/null
done


3. Test High 5xx Alert PromQL
-----------------------------

curl -sG \
  http://127.0.0.1:9090/api/v1/query \
  --data-urlencode 'query=(
    100 *
    (
      sum(
        rate(
          havenbridge_http_requests_total{
            namespace="havenbridge",
            status_code=~"5..",
            route!~"/health/(live|ready)"
          }[5m]
        )
      )
      or vector(0)
    )
    /
    sum(
      rate(
        havenbridge_http_requests_total{
          namespace="havenbridge",
          route!~"/health/(live|ready)"
        }[5m]
      )
    )
  ) > 5
  and
  sum(
    rate(
      havenbridge_http_requests_total{
        namespace="havenbridge",
        route!~"/health/(live|ready)"
      }[5m]
    )
  ) > 0' \
  | jq '.data.result'

6. Check Current P95 Latency
----------------------------

  http://127.0.0.1:9090/api/v1/query \
