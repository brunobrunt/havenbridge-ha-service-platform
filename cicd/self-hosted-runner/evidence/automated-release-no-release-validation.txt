HavenBridge Automated Release and CD No-Release Validation
==========================================================

Purpose
-------

Validate that the HavenBridge CI/CD pipeline automatically progresses from
CI to Release to CD without requiring a manual Release workflow trigger.

This validation specifically tests the safe "no release required" path.

Expected Flow
-------------

Developer
   |
   | git push main
   v
HavenBridge CI
   |
   | tests / build / validation
   |
   +---- FAIL -----------------------> STOP
   |
   +---- PASS
          |
          v

          |
          v

     |
     +---- release_needed=false

     |          v
     |     workflow succeeds
     |
     v

Safety Behaviour Confirmed
--------------------------

The validation proved that:

1. Release no longer requires a manual workflow trigger after successful CI.

2. Documentation, CI/CD, observability, and other non-application changes do
   not automatically create a HavenBridge API version.

3. A no-release decision is treated as a successful workflow result rather
   than a failure.

4. CD does not deploy merely because the Release workflow succeeded.

5. CD verifies that a semantic-version tag exists for the exact release commit
   before allowing the deployment job to run.

6. The existing HavenBridge application remains on v0.7.0 when no new
   application release is required.
