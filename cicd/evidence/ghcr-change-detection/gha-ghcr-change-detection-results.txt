Validated Conditional Logic
---------------------------

The publication steps use:

    github.event_name == 'push'

AND:

    github.ref == 'refs/heads/main'

AND:

    steps.api_changes.outputs.changed == 'true'


This can be read as:

    Push event?
        ↓ YES

    Main branch?
        ↓ YES

    HavenBridge API changed?
        ↓
     YES / NO

    YES
        ↓
    GHCR login
    GHCR tag
    GHCR push

    NO
        ↓
    Skip all GHCR publication steps
